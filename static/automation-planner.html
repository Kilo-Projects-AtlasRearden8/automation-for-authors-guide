Printable Automation Planner

Print this page and fill it in by hand. It's your weekly reminder of which author-admin tasks to do, when, and with which tool.

Print: File → Print → Landscape (Portrait works fine too).

A low-energy, ADHD-friendly approach

You don't have to do every task every week. In fact, please don't. Pick one day, pick one task. Rest is built into the plan. If you miss a week, that's fine — just start again where you are.

Energy tip: if a task feels too big, shrink it. "Draft a newsletter" can become "write one sentence about what I'm working on." Small steps count.

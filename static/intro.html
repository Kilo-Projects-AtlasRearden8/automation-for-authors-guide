Welcome

You wrote a book. Now comes the admin: newsletter drafts, social posts, KDP uploads, reader emails. This guide walks you through automating those tasks with free tools — step by step, in plain English, never condescending. No coding experience required.

No coding experience needed. Every script is "no-code friendly": copy it, run it, and read what it does. Nothing moves or deletes your original files without you saying so.

The four automations

AutomationWhat it doesRead more
Newsletter Drafts Draft newsletter emails locally before you send them. Read more

KDP Uploads Prep your book metadata with a pre-upload checklist. Read more
Reader Emails Draft thank-you, ARC, and new-release emails locally. Read more

Quick start

  1. Read Safety First before running anything.

  2. Pick an automation and follow its page step by step.

  3. Run the script in dry-run mode (the default) — it shows what it would do without changing anything:

    python3 scripts/draft_newsletter.py --book "My Book" --update "Chapter 3 done"

  4. When you're comfortable, back up your folder and run with --apply to write the draft file:

    python3 scripts/draft_newsletter.py --book "My Book" --update "Chapter 3 done" --apply

What you need

  • A computer (Windows, Mac, or Linux)
  • Python 3 (built-in on Mac and Linux; free from python.org on Windows)
  • A web browser
  • A text editor
  • About an hour to walk through everything
